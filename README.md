# INSM — Instituto Nuestra Señora de la Merced

Sitio estático optimizado para GitHub Pages.

## Publicación
En GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

El archivo `index.html` es la página de inicio y `.nojekyll` permite servir los archivos estáticos directamente.

## Nota sobre URLs
Las URLs absolutas de Vercel fueron eliminadas del funcionamiento del sitio para que pueda publicarse dentro de un repositorio de GitHub Pages.
